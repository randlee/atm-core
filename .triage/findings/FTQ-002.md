# FTQ-002: Fixed-duration sleep in tests

## Pattern
```
sleep(Duration::from_millis(50))
thread::sleep.*50
tokio::time::sleep.*50
sleep(Duration::from_millis(200))
```

## Crates Affected
- atm-daemon

## Sprint Origin
R.14 (first reported R.14-QA-5)

## Status
open

## Description
Tests use fixed `sleep(50ms)` or similar hardcoded delays to wait for async conditions. These are timing-sensitive and flaky on slow CI machines. Replace with `tokio::time::timeout` + condition polling or explicit channel/signal synchronization.

## Fix
Replace fixed sleep with bounded polling: `tokio::time::timeout(Duration::from_secs(5), async { loop { if condition() { break; } tokio::time::sleep(Duration::from_millis(10)).await; } })`.
