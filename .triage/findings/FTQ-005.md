# FTQ-005: Shared-state race in singleton_guard_recovers_stale_owner test

## Pattern
```
singleton_guard_recovers_stale_owner
stale_owner
#\[test\].*singleton_guard
```

## Crates Affected
- atm-daemon

## Sprint Origin
R.15 (first reported R.15-QA-5)

## Status
open

## Description
`singleton_guard_recovers_stale_owner` test at `tests.rs:148` observes global singleton state that can be polluted by parallel test execution. When `--test-threads > 1`, a prior test's guard may not have released the global before this test runs, causing nondeterministic failure. Fix: add `#[serial(env)]` attribute or restructure to avoid shared global state dependency.

## Fix
Add `#[serial(env)]` attribute to `singleton_guard_recovers_stale_owner` test (and any other test that reads/writes the global singleton guard without isolation). Alternatively restructure to use in-process transport double with no shared global.
