# FTQ-001: OnceLock / process-global state in tests

## Pattern
```
OnceLock
static.*Once
LazyLock
static.*Mutex.*=.*Mutex::new
```

## Crates Affected
- atm-daemon

## Sprint Origin
R.15 (first reported R.15-QA-3 as BLOCKING)

## Status
open

## Description
`OnceLock<T>` (or similar process-global statics) used to share dispatcher/state across tests. Causes race conditions when tests run with `--test-threads > 1`. Each test must construct its own dispatcher; no shared global state permitted in test modules.

## Occurrences
| Branch | File | Line | Snippet | Fixed |
|--------|------|------|---------|-------|
| R.15 | crates/atm-daemon/src/tests.rs | 28-29 | `static DISPATCHER: OnceLock<DaemonRequestDispatcher>` | open |
| R.16 | crates/atm-daemon/src/tests.rs | 28-29 | OnceLock removed ✓ | fixed (R.16-FIX-R2 d698dee) |
| R.17 | crates/atm-daemon/src/tests.rs | 28-29 | same — sweep needed | open |

## Fix
Replace `OnceLock<DaemonRequestDispatcher>` with per-test dispatcher construction. No shared global state in test modules.
