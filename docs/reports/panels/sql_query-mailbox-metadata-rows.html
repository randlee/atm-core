Query Mailbox Metadata Rows

Public sqlite-store method `query_mailbox_metadata_rows`.

SSOT: docs/atm-rusqlite/sql_query-mailbox-metadata-rows.mmd

This SQL path returns bounded mailbox header rows. It joins immutable message rows with visibility and ack projections, then decodes the row set into `MailboxMetadataRow` values.

CREATE TABLE IF NOT EXISTS ack_state (
    team TEXT NOT NULL,
    agent TEXT NOT NULL,
    message_key TEXT NOT NULL,
    pending_ack_at TEXT NULL,
    acknowledged_at TEXT NULL,
    updated_at TEXT NULL,
    PRIMARY KEY (team, agent, message_key),
