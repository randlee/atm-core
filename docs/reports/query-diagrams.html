SQL Queries

SQLite is the mailbox SSOT. These panels show the target query shapes: status-first selection, deleted-row exclusion in normal queries, and full message fetch only when a message must actually be rendered.

SQLite boundary method `MailStore::load_message`.

Open panel

SSOT: docs/atm-rusqlite/sql_load-message.mmd

This SQL-boundary path shows the direct immutable-row load. It currently reads only `mail_messages`, rebuilds one `MailStoreMessageRecord`, and returns `None` when no row exists.

mail_messages

SSOT: crates/atm-rusqlite/src/shared_db.rs

CREATE TABLE IF NOT EXISTS mail_messages (
    team TEXT NOT NULL,
    agent TEXT NOT NULL,
    message_key TEXT NOT NULL,
    envelope_json TEXT NOT NULL,
    from_agent TEXT NOT NULL,
    message_text TEXT NOT NULL,
    summary TEXT NULL,
    message_at TEXT NOT NULL,
    message_id TEXT NULL,
    parent_message_id TEXT NULL,
    thread_mode TEXT NULL CHECK(thread_mode IS NULL OR thread_mode IN ('add-details', 'supersede')),
    stale_at TEXT NULL,
    imported_from TEXT,
    recorded_at TEXT,
    CHECK(message_key GLOB 'atm:*' OR message_key GLOB 'ext:*'),
    PRIMARY KEY (team, agent, message_key)
);
