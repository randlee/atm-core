CLI Interface

These panels show the retained CLI command surfaces and their target command-to-daemon or command-to-service flows, including error paths.

atm clear

Status mutation without content-row deletion.

Open panel

SSOT: docs/atm/diagrams/atm-clear.mmd

This path should mutate only message-status for normal clear or delete operations and leave hard deletion to retention cleanup policy.

atm doctor

Health and diagnostic flow.

Open panel

SSOT: docs/atm/diagrams/atm-doctor.mmd

This diagnostic flow should report config, runtime, and optional store-health failures clearly without mutating mailbox state.

atm list

Bounded metadata-only mailbox query.

Open panel

SSOT: docs/atm/diagrams/atm-list.mmd

This query should start from message-status, exclude deleted rows, collapse superseded rows in normal mode, and fetch only header fields for selected keys.

atm log

Observability query and follow service path.

Open panel

SSOT: docs/atm/diagrams/atm-log.mmd

This flow should stay behind the observability boundary and must not add ad hoc CLI-side file parsing.

atm members

Team roster query path.

Open panel

SSOT: docs/atm/diagrams/atm-members.mmd

This flow should read deterministic roster state through the team-admin boundary and surface query failures clearly.

atm read

Single-message read with status-first selection.

Open panel

SSOT: docs/atm/diagrams/atm-read.mmd

This read path should select from message-status first, hide deleted rows in normal mode, and fetch full content only for the chosen key.

atm ack

Ack-state mutation and optional reply creation.

Open panel

SSOT: docs/atm/diagrams/atm-send-ack.mmd

This path should mutate only status plus any explicit reply row, then run post-commit effects without changing durable truth on hook or nudge failure.

atm send

Compose and persist one message, then run post-commit effects.

Open panel

SSOT: docs/atm/diagrams/atm-send-compose.mmd

This path should validate input, commit SQLite first, then run post-commit hooks or advisory nudges without letting any side effect outrun durable truth.

atm teams

Team-admin mutation and recovery path.

Open panel

SSOT: docs/atm/diagrams/atm-teams.mmd

This flow should stay in the retained team-admin surface and report config or store failures without bypassing the boundary.
