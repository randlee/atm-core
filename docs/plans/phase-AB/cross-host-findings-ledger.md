# Phase AB Cross-Host Findings Ledger

## Purpose

Record verified `Phase AB` smoke and interoperability findings.

## Record Schema

Each finding entry must record:

- `finding_id`
- `discovered_in`
- `linked_row_id`
- `summary`
- `severity`
- `owner`
- `status`
- `revalidation_result`
- `notes`
